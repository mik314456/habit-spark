# Habit Spark — AI Habit Tracker

> Built in 10 days. Solo. Zero budget. Fully deployed.

Live: [habitsparkz.vercel.app](https://habitsparkz.vercel.app)

---

## What it is

An AI habit tracker with a sarcastic coach built on Claude API. The abrasive personality isn't a gimmick — it's a deliberate retention mechanism designed to stand out in a category full of gentle nudges.

## Product decisions

- **Cut onboarding from 8 to 4 steps** after identifying drop-off through session analysis
- **Chose sarcasm as a differentiator** — built the AI coach personality as a product decision, not a design accident
- **Scoped ruthlessly** — every feature was justified against the core job: build the habit

## Stack

React · TypeScript · Supabase · Claude API · Framer Motion · Vercel
